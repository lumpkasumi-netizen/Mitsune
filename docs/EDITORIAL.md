# 記事編集ルール

- 公開ブランド表記は `Mitsune`。日本語名への置換はしない。
- 記事は導入・使い分け・入力例・分類へのリンク・日本語/英語検索・辞典・FAQ・関連記事を基本とする。
- 見出し直下の定型説明 `mitsune-section-lead` は再導入しない。見出しから表へ進める簡潔さを保つ。
- 辞典行は日本語名・コピー用英語・必要な補足・コピーボタンを揃える。類似語を機械的に削除しない。英語・コピー値・既存行順は目的がなければ保持する。
- 入力例と生成画像を検証した実例を区別する。未検証の入力例を「再現できる」「必ず効く」と書かない。モデル依存の英語表現を専用タグと断定しない。
- ポーズでは全身姿勢・手足・動作・構図を区別する。立つ/座るなど競合する指定を重ねない。
- テーマ記事は衣装・小物・背景・ポーズを横断する。専門記事との重複は用途があれば許容する。
- 説明へ「成人」などの限定文を一律に繰り返し追加しない。既存のコピー用英語は別管理し、説明調整のついでに変更しない。
- タイトルを変える場合は導入、抜粋、ホームカード、手書きの関連記事名、BreadcrumbListも確認する。FAQ本文とFAQPage JSON-LDの内容を一致させる。
- SEO出力はテーマのwp_headへ集約済み。header.phpへ直接のSEO出力を戻さず、canonicalやGA4を二重にしない。
- コピーには通常/コンマ付きの2モードがある。既存 `.mitsune-copy` と `data-prompt` を使う。本文や検索語をGA4へ送信しない。
- 画像追加は別途、送信前にEXIF・GPS・生成プロンプト等の埋め込みメタデータを除去・検証する。既存画像を勝手に切り抜かない。
- PV・クリック・コピー操作数・ユーザー数は区別する。検索効果は同じURLと期間条件で比較する。
